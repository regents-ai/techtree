Test your Skill

Make practice tasks from your Skill, then see whether it helps your agent.

Three steps · You approve every paid step

Rather have your agent do it? Give it one line from the home page →

01 Make the tasks

Techtree reads your Skill and plans practice tasks with you. Before anything is sent to a model, it shows you what will happen and waits for your yes.

regents techtree forge inspect-skill path/to/your-skill regents techtree forge plan SOURCE_ID --provider PROVIDER --model MODEL # Look over the plan, fix anything, then build and keep the tasks that work.

The tasks you keep become your set. A few of them are kept aside, so no later version of your Skill can learn from them.

02 Run them both ways, then compare

Your agent works the same tasks twice, with the same model and the same limits: once without the Skill, once with it.

regents techtree forge run --arm baseline --collection COLLECTION_ID --provider PROVIDER --model MODEL regents techtree forge run --arm candidate --collection COLLECTION_ID --provider PROVIDER --model MODEL --skill path/to/your-skill regents techtree forge compare BASELINE_RUN_ID CANDIDATE_RUN_ID

The comparison says whether the Skill helped, hurt, was mixed or made no difference, on every task and on the tasks kept aside. It also writes a report you can open in your browser. See a finished one →

03 Improve it once, if you want to

Get what a new version may learn from. The tasks kept aside are never included.

regents techtree uplift context COMPARISON_ID regents techtree uplift prepare --from-run COMPARISON_ID --candidate-skill path/to/revised-skill

Then run the start line it prints. The new version is judged only on the tasks kept aside.
