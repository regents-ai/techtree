# Techtree Hello World Climb v0.1 Founder Closeout Pack

This revised pack supersedes the earlier `climb-v0.1-founder-closeout` pack.

Changes:

1. The public introductory product is now **Techtree Hello World**.
2. The public Climb reference is `hello-world-climb@1`.
3. BranchCode v1 remains the synthetic underlying task family.
4. The starter Skill is now `hello-world-starter-v1`.
5. `rich-terminal-output` has been removed from the product release.
6. Terminal and gateway result presentation is deterministic
   `techtree-python` behavior.
7. The only founder-supplied operator Skill used at runtime is
   `skill-improver`.

The two Skill files are drafts until they pass committed contracts, paid
calibration, founder byte-level approval, and final release hashing.

The draft frontmatter recommends `license: MIT`. Change it before hashing when
a different founder-approved license is required.
