# Techtree Verify

Proof your important workflows work. For teams that ship quickly: we check the workflows you choose, reproduce every failure and leave you a suite you can run again.

## Agent Wallet Bench

Our own bench, read on 28 October 2026: 12 coding agents tested; all 35 working wallets they set up left the controlling secret in a plain file. 4 safety failures in 85 judged tests. [See the bench](/wallet-bench).

## You get

- Agreed coverage: the workflows that matter to you, and the behaviour each must show.
- Reproducible failures: every failure with the steps and evidence to see it again.
- A repeatable suite: one script that reruns every check after each release.
- A clear report: each check, its result and its evidence, in one table.

## How an engagement runs

1. Scope: we agree the workflows and the behaviour each must show.
2. Checks: we run every check and keep the evidence.
3. Report: you get the results, with the steps to reproduce each failure.
4. Fixes verified: after your repair, the suite runs again.
