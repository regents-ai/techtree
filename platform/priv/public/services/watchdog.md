# Techtree Watchdog

Keep watch on the sites you own. A monthly subscription for teams: you list the web addresses you own, prove they're yours, and we safely test them for security weaknesses the way a careful attacker would, inside limits you agree, and nothing else.

For a one-off check instead, see [Techtree Verify](/services/verify) and [Techtree Cyber Assist](/services/cyber-assist).

## How it works

1. List: you add the web addresses you want watched, each one a site you own.
2. Prove: you prove each site is yours, with a short DNS record or a small file at a set address. No proof, no testing.
3. Watch: we test the proven addresses for weaknesses, inside the limits you agreed.
4. Report: you get only the weaknesses we reproduced, each with a fix, and we retest after you fix.

## The rules we follow

- Only sites you've proven you own.
- Only the addresses you list, nothing beyond them.
- A rate you agree, and never anything that deletes or changes your data.
- Test accounts you make for us, never a real person's login.
- We stop the moment you ask.

## You get

- Reproduced findings: only weaknesses we could show again, each with how serious it is.
- A fix for each: clear repair advice, most urgent first.
- A retest: after you fix, we check the weakness is gone.

Monthly, per site. Ask us for the price.
