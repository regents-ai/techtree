# About Techtree

Open-source tools. Paid custom projects.

## Team

Techtree is built and run by Regents Labs, an agentic product lab whose products share one token, REGENT, instead of equity. We build better agents for businesses: custom Skills, evaluations, training environments and open-weight models, built around a team's own workflows, with results the team can measure. Techtree's own tools are open source under the MIT licence. Projects are paid, scoped with each team and delivered by people.

- **Sean Brennan**, founder. [X](https://x.com/seanwbren) · [LinkedIn](https://www.linkedin.com/in/seanwbren)

## Experience

- Techtree's open-source tool runs an agent on the same tasks with and without a Skill, and keeps a signed Result anyone can check offline. [Docs](/docs) show how to run it.
- [Results](/results) lists what has been published, each with how to check it, including a Skill comparison Techtree ran itself.
- [Wallet Bench](/wallet-bench) shows which coding agents can set up which wallet tools safely.
- [Formal](/formal) explains what formal verification proves, and how to send code to be proved.
- Regents Labs also builds [Regents](https://regents.sh), [Autolaunch](https://autolaunch.sh) and [Patchbay](https://patchbay.help).

## Projects

1. Tell us about the workflow you want to improve: book a call from any service page, or write to [build@regents.sh](mailto:build@regents.sh).
2. Together we agree what success means, how it is scored, and the scope and limits of the work.
3. We measure a baseline, do the work, and run the final test on cases the work never saw. You receive what we built, with a report of what changed.

The services are [Skills](/services/skills), [Evals](/services/evals), [Environments](/services/environments), [Models](/services/models) and [Security](/services/security).

## Contact

### Questions

Ask about Techtree on [the Techtree page at Patchbay](https://patchbay.help/techtree.sh), where people and agents answer in the open.

### Email

Write to [build@regents.sh](mailto:build@regents.sh) for a project, or for anything that should stay private, such as a request to remove something.

### Issues

The code is public at [github.com/regents-ai/techtree](https://github.com/regents-ai/techtree). Report bugs and ask for features in [GitHub issues](https://github.com/regents-ai/techtree/issues). Pull requests are welcome too.

### Security reports

Send security reports to [build@regents.sh](mailto:build@regents.sh) first, or use GitHub's private vulnerability reporting for the repository. Please do not post them publicly, in an issue or anywhere else, before we have replied. Say which part is affected, which release or commit you tested, and how to reproduce the problem.
