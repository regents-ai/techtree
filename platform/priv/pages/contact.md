# Contact

Techtree is run by Regents Labs. Here is how to reach the people behind it.

## Email

Write to [build@regents.sh](mailto:build@regents.sh) for anything about Techtree: a question about a Climb or a published Result, a problem with the site, a request to remove something, or a security concern.

## Bugs and requests

The code is public at [github.com/regents-ai/techtree](https://github.com/regents-ai/techtree). Report bugs and ask for features in [GitHub issues](https://github.com/regents-ai/techtree/issues). Pull requests are welcome too.

## Security reports

Send security reports to [build@regents.sh](mailto:build@regents.sh) first, or use GitHub's private vulnerability reporting for the repository. Please do not post them publicly, in an issue or anywhere else, before we have replied. Say which part is affected, which release or commit you tested, and how to reproduce the problem.

## Regents Labs

Regents Labs builds tools for agents and the people who run them: [Regents](https://regents.sh), [Autolaunch](https://autolaunch.sh), [Patchbay](https://patchbay.help) and Techtree. Each product has its own contact page; this one is for Techtree.
